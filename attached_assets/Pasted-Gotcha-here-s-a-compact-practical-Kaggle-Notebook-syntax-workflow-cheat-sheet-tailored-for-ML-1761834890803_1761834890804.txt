Gotcha—here’s a compact, practical **Kaggle Notebook syntax + workflow cheat-sheet** tailored for ML/competitions like CAFA-6.

# 1) Paths & filesystem

* **Read-only inputs**: `/kaggle/input/<dataset-or-competition-name>/...`
* **Your writable scratch**: `/kaggle/working/` (temp during a run)
* **Output artifacts** (persist when you “Save Version”): anything you leave in `/kaggle/working/` becomes available as notebook **Output** files.

```python
import pandas as pd, os, numpy as np

# Examples:
train = pd.read_csv("/kaggle/input/cafa-6-protein-function-prediction/train.csv")
fasta_path = "/kaggle/input/cafa-6-protein-function-prediction/train.fasta"

# Write artifacts (models, embeddings, submission):
os.makedirs("/kaggle/working/embeddings", exist_ok=True)
np.save("/kaggle/working/embeddings/A0A0C5B5G6.npy", np.random.randn(1280).astype("float32"))
```

# 2) Python, shell, and “cell magics”

* **Python cells** are default.
* **Shell**: prefix with `!` for single lines, or use `%%bash` for multi-line.
* **Magics**: `%pip`, `%conda`, `%time`, `%env`, `%%time`, `%%writefile`, etc.

```python
# Install packages (prefer %pip over !pip so the same environment is used)
%pip install -q fair-esm  # if internet enabled; else use wheel datasets (see §5)

# One-liner shell
!nvidia-smi

# Multi-line shell
%%bash
ls -lah /kaggle/input
echo "Building indices..."

# Write a small helper script from a cell
%%writefile /kaggle/working/utils.py
import numpy as np
def fuse_vecs(a, b): return np.concatenate([a, b], axis=0)
```

# 5) Installing packages (with & without internet)

* **With internet enabled (Notebook setting)**: use `%pip install ...`.
* **Without internet** (typical for competition submissions):

  1. Create a private **Dataset** that contains your prebuilt wheels/tarballs.
  2. Add that Dataset as an **Input** to the notebook.
  3. Install from local files:

```python
# offline install from attached wheel dataset
!ls /kaggle/input/my-wheels
%pip install -q /kaggle/input/my-wheels/fair_esm-2.0.0-py3-none-any.whl
```

# 9) Persisting models/embeddings for later versions

Anything you leave under `/kaggle/working/` at the end of a run shows up as **Output**. You can then “Create Dataset” from that Output to reuse artifacts offline later.

```python
import joblib, os
os.makedirs("/kaggle/working/models", exist_ok=True)
joblib.dump({"weights": np.random.randn(3072, 2)}, "/kaggle/working/models/head.pkl")
```

# 11) Common CAFA-6 patterns (quick plugs into the above)

* **Load FASTA** and map IDs:

```python
from Bio import SeqIO
records = list(SeqIO.parse("/kaggle/input/cafa-6-protein-function-prediction/train.fasta", "fasta"))
ids = [r.id for r in records]
seqs = [str(r.seq) for r in records]
```

* **Generate ESM-2 embeddings** (if internet enabled and fair-esm allowed):

```python
%pip install -q fair-esm
from esm import pretrained
import torch, numpy as np, os
model, alphabet = pretrained.esm2_t33_650M_UR50D()
batch_converter = alphabet.get_batch_converter()
model.eval()

os.makedirs("/kaggle/working/esm2_npy", exist_ok=True)
batch = list(zip(ids, seqs))
for i in range(0, len(batch), 8):
    labels, strs, toks = batch_converter(batch[i:i+8])
    with torch.no_grad():
        out = model(toks, repr_layers=[33], return_contacts=False)
    reps = out["representations"][33]            # [B, L, 1280]
    means = reps.mean(dim=1).cpu().numpy()       # [B, 1280]
    for j, pid in enumerate(ids[i:i+8]):
        np.save(f"/kaggle/working/esm2_npy/{pid}.npy", means[j].astype("float32"))
```

* **Fuse with other pLMs**: read `*.npy` by ProteinID and `np.concatenate`.
