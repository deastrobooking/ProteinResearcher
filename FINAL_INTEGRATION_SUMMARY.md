2. **Configure** algorithm mode and data mode in cell 2
3. **Attach** CAFA-6 competition datasets
4. **Run all cells** sequentially
5. **Download** `submission.tsv` from outputs

### Option 2: Local Development

```python
pipeline = CAFA6ProductionPipeline(config)
results = pipeline.run_full_pipeline()
```
